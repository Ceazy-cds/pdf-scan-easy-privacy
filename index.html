Privacy Policy - PDF Scan Easy

Last updated: September 29, 2026

PDF Scan Easy is designed with privacy in mind. The application allows users to scan, import, edit and create PDF documents directly on their device.

Documents and Images

Documents, scanned pages, imported images and PDF files created with PDF Scan Easy are processed locally on the user's device.

PDF Scan Easy does not require an account and does not upload the user's documents to a Ceazy server or cloud service.

Camera and Image Access

PDF Scan Easy may use the device camera when the user chooses to capture a document. The application may also allow the user to select existing images or documents from the device.

Access occurs only when required by a feature selected by the user.

File Storage and Sharing

PDF files created by the application can be saved on the device or shared using applications and services selected by the user.

When a user chooses to share a document, the selected third-party application or service may process that document according to its own privacy policy.

Advertising

The free version of PDF Scan Easy may display advertisements provided by Google AdMob.

Google and its advertising partners may process certain device information, advertising identifiers, IP address, diagnostic information and interaction data in order to provide, measure and improve advertising, subject to applicable privacy requirements and the user's consent choices.

PDF Scan Easy does not control the data processing performed independently by Google AdMob.

Pro Version

If the user upgrades to the Pro version, advertisements are disabled. The application does not request or display AdMob advertisements while the Pro version is active.

Internet Access

The application may use an Internet connection for services such as advertising. The core PDF scanning and document creation functionality is designed to work locally on the device.

Personal Information

PDF Scan Easy does not require registration, login or the creation of a user account. Ceazy does not operate a server for storing the user's scanned documents or PDFs.

Children's Privacy

PDF Scan Easy is not specifically directed at children. The application does not knowingly request personal information directly from children.

Changes to This Privacy Policy

This Privacy Policy may be updated when application features or third-party services change. Any updates will be published on this page.

Contact

For questions regarding this Privacy Policy, please contact the developer through the contact information provided on the Google Play Store listing.
